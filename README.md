# Gravitation

**SSH-клиент** (Tauri v2 + React/TS): серверы, ключи, скрипты, прокси, терминалы (PTY) и SFTP-файлы — в стиле Termius.
Выделен из режима «SSH Client» приложения [Singularity](../Singularity) с тем же интерфейсом.

## Возможности

- **Units** — серверы, ключи (импорт и генерация), скрипты, прокси; порядок перетаскиванием.
- **Терминал** — несколько PTY-сессий на сервер, вставка скриптов, темы терминала.
- **Файлы** — SFTP: просмотр, загрузка/скачивание, переименование, удаление, редактор текста.
- **Logs** — журнал подключений и команд (секреты в нём маскируются).
- **Безопасность** — пароли и ключи хранятся зашифрованными (AES-256-GCM), мастер-ключ — в Windows Credential Manager; host key закрепляется при первом подключении.

При первом запуске серверы, ключи, скрипты, прокси, логи и настройки терминала один раз переносятся из базы Singularity (секреты перешифровываются ключом Gravitation).

## Запуск

Требуется Rust toolchain ([rustup.rs](https://rustup.rs)):

```bash
npm install
npm run tauri:dev     # dev-сервер на http://localhost:1430
npm run tauri:build   # .msi/.exe для Windows
```

## Структура

```
src/            # React UI (дизайн-система в src/styles.css, компоненты в src/components)
src-tauri/      # Rust: ssh.rs (соединения, PTY, SFTP), proxy.rs, vault.rs, import.rs
```
